# Mapa com OpenStreetMap e coordenadas guardadas

O mapa usa Leaflet com mapas do OpenStreetMap em vez da API do Google Maps, que exige chave e cartão de crédito. Quando os noivos guardam a morada do local, o servidor converte-a em coordenadas uma única vez (geocodificação com o Nominatim) e guarda `latitude`/`longitude` no casamento; os convidados nunca fazem esse pedido. Para chegar lá, o convite oferece ligações diretas para Google Maps, Waze e Apple Maps. Os noivos podem corrigir o pino à mão se a morada não for encontrada com precisão.
